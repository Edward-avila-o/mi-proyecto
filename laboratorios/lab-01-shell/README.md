## Objetivo

Preparar el entorno de trabajo en Kali Linux: estructura de carpetas (reconocimiento, evidencias, reportes), identificación del sistema (`whoami`, `hostname`, `uname -a`), configuración de red (`ip a`, `ip route`) y revisión de servicios locales (`ss -tuln`, `nmap 127.0.0.1`).
