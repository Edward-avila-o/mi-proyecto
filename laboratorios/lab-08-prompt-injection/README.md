## Objetivo

Analizar qué es el prompt injection, su relación con SQL injection y XSS, la separación entre instrucciones del sistema y entrada del usuario, sus riesgos en aplicaciones conectadas a APIs o bases de datos y estrategias de mitigación (aislamiento de contexto, validación de entradas y salidas, mínimo privilegio y aprobación humana).
