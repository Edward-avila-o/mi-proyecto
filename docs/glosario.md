# Glosario técnico y metodológico

> Parte del documento **EDWARD_FW** · versión completa en [`docs/EDWARD_FW_Framework.docx`](EDWARD_FW_Framework.docx) y [PDF](EDWARD_FW_Framework.pdf).


| Término              | Definición                                                                                    |
|----------------------|-----------------------------------------------------------------------------------------------|
| Red Team             | Equipo o función que emula comportamientos adversarios bajo autorización.                     |
| Blue Team            | Función encargada de protección, detección y respuesta.                                       |
| Purple Team          | Colaboración sistemática entre actividades ofensivas y defensivas.                            |
| SOC                  | Centro o función de operaciones de seguridad y monitoreo.                                     |
| CSIRT                | Equipo de respuesta a incidentes de seguridad informática.                                    |
| Pentesting           | Prueba técnica autorizada para evaluar vulnerabilidades.                                      |
| OSINT                | Obtención y análisis de información de fuentes abiertas.                                      |
| Footprinting         | Reconocimiento inicial de información y superficie de exposición.                             |
| Superficie de ataque | Conjunto de puntos potencialmente explotables de un sistema.                                  |
| Vulnerabilidad       | Debilidad que puede ser aprovechada por una amenaza.                                          |
| Amenaza              | Circunstancia o actor con potencial de causar daño.                                           |
| Riesgo               | Efecto de incertidumbre asociado con escenarios y consecuencias.                              |
| SIEM                 | Gestión y correlación de información y eventos de seguridad.                                  |
| EDR                  | Detección y respuesta en equipos finales.                                                     |
| IOC                  | Indicador observable de posible compromiso.                                                   |
| TTP                  | Tácticas, técnicas y procedimientos de actores adversarios.                                   |
| MITRE ATT&CK         | Base de conocimiento de técnicas y tácticas adversarias.                                      |
| OWASP                | Comunidad y recursos de seguridad de aplicaciones.                                            |
| Hardening            | Fortalecimiento de configuraciones y controles.                                               |
| Cadena de custodia   | Registro de obtención, manejo y transferencia de evidencia.                                   |
| Evidencia digital    | Información digital relevante para una evaluación o investigación.                            |
| DFIR                 | Forense digital y respuesta a incidentes.                                                     |
| Prompt injection     | Instrucciones maliciosas destinadas a alterar el comportamiento previsto de un sistema LLM.   |
| Fase                 | Conjunto delimitado de actividades y entregables.                                             |
| Instrumento          | Medio estructurado para recolectar o evaluar evidencias.                                      |
| Hallazgo             | Resultado documentado y sustentado de una prueba.                                             |
| Mitigación           | Acción destinada a reducir un riesgo.                                                         |
| Validación           | Proceso de comprobación del funcionamiento y utilidad del marco.                              |
| CVSS                 | Sistema estándar para puntuar la severidad de una vulnerabilidad de 0.0 a 10.0.               |
| Hash (SHA-256)       | Huella digital de un archivo; si el archivo cambia, el hash cambia.                           |
| Línea base           | Estado inicial documentado de la configuración y los controles, usado para comparar.          |
| Reglas de compromiso | Acuerdo previo que define qué se puede probar, cómo, cuándo y con qué límites.                |
| Esteganografía       | Técnica para ocultar información dentro de otro archivo, como una imagen.                     |
| DVWA                 | Aplicación web vulnerable a propósito, usada para practicar pruebas en un entorno controlado. |
| UML                  | Lenguaje gráfico estándar para representar actores, procesos e interacciones.                 |
| Pull Request         | Solicitud en GitHub para revisar y aprobar cambios antes de unirlos a la rama principal.      |
