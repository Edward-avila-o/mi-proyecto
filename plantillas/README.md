# Plantillas

Formatos que se diligencian al aplicar EDWARD_FW. Los archivos `.csv` se abren en Excel. La primera fila de datos es una guía y se reemplaza por los datos reales.

| Archivo | Anexo | Para qué sirve |
|---|---|---|
| [`ficha-laboratorio.md`](ficha-laboratorio.md) | Sección 10.1 | Describir un laboratorio nuevo con el formato estándar |
| [`matriz-casos-prueba.csv`](matriz-casos-prueba.csv) | A | Registrar cada caso de prueba y su resultado |
| [`matriz-hallazgos-riesgos.csv`](matriz-hallazgos-riesgos.csv) | B | Consolidar hallazgos con probabilidad, impacto y severidad |
| [`registro-evidencias.csv`](registro-evidencias.csv) | C | Registrar evidencias con su hash SHA-256 y custodia |
| [`plan-mitigacion.csv`](plan-mitigacion.csv) | D | Definir el tratamiento de cada hallazgo |
